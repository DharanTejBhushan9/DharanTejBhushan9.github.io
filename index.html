02 / how it works

From a market tick to a trader's phone.

The HedgeWithAI pipeline I work across, stage by stage. Pick a stage.

Ingest

An EventBridge-scheduled Lambda pipeline fetches candlestick (OHLCV) data at second, minute and daily intervals, into a historical archive on S3 and DynamoDB.

  • EventBridge
  • AWS Lambda
  • S3
  • DynamoDB
  • Python

Validate

Market data arrives with gaps and bad values, so nothing runs on it until it's checked. Purpose-built AI agents verify every batch for missing and incorrect candles first.

  • Data validation
  • ETL
  • AI agents

Research

New strategies come from the archive: candlestick-pattern and quarterly market-trend analysis, plus LLM-assisted research on the OpenAI API with retrieval-augmented generation. Every candidate is backtested, then tested out of sample. A reusable harness runs the whole battery without new code.

  • Backtesting
  • Out-of-sample tests
  • OpenAI API
  • RAG
  • Pandas

Models

Python modules compute indicators and features from candle data; Amazon SageMaker endpoints and the platform's signal algorithms turn them into trend predictions and entry/exit signals. LLM sentiment analysis adds context.

  • SageMaker
  • Feature engineering
  • Sentiment analysis
  • Python

Deliver

Signals go out as pre-market and entry/exit alerts through SES, with SQS between stages, and stream over WebSockets to Angular and React dashboards and the React-based iOS and Android apps. Charles Schwab integration with OAuth brings in account data and order workflows.

  • SES
  • SQS
  • WebSockets
  • Angular
  • React
  • Node.js
  • Schwab API

Operate

GitHub Actions, AWS CodePipeline, AWS SAM and Docker take every change through the test suite and the test and main environments before production. CloudWatch alarms with Kinesis-based log filtering and SES error alerts catch problems before traders do.

  • GitHub Actions
  • CodePipeline
  • AWS SAM
  • Docker
  • CloudWatch
  • Kinesis
